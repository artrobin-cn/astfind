# Astfind App Icon Concepts

## 第一轮：渐变三版（参考稿）

三版 1024×1024 图标，共用同一套 macOS 圆角底板、留白与投影规范；每版附 `.icns`（16–1024 全尺寸）和 128/64/32/16 px 暗底检查。

| 方案 | 概念 | 一句话 |
|---|---|---|
| **A · 深空透镜** | 放大镜 + 文档 | 最直白的搜索符号，稳、通用，一眼知道是搜索工具 |
| **B · A 星火** | 品牌字母 A + 金色星火 | 品牌识别最强，"Ast" 的星火点出"找到"，适合做长期记忆点 |
| **C · 多源层叠** | 三层来源 + 透镜 | 强调本机 / SSD / NAS 统一搜索，最贴近 Astfind 的差异化 |

文件：

- `preview.png` — 三版对比 + 小尺寸实尺寸检查
- `a-deep-lens-1024.png` / `b-monogram-1024.png` / `c-layers-1024.png` — 1024 原图
- `a-deep-lens.icns` / `b-monogram.icns` / `c-layers.icns` — 可直接接入 `.app`

## 第二轮：扁平 / 线条七版（已定稿 C1++）

A 与 C 两个方向重画，去掉渐变与光泽，改为白色底板 + 平涂或墨线（飞书 / ChatGPT / Qoder 的笔法）。
详见 [`flat/README.md`](flat/README.md)，对比图 `flat/preview-flat.png`，决版放大对比 `flat/c1-scale.png`。

**已选 C1++ · 层叠镜外（放大版）**，`flat/c-flat-layers-bigger.icns` → `AstfindKit/Resources/AppIcon.icns`，v0.2.7 装机。
它是在 C1 基础上升级：整图 62%→75%、镜圈 R116→R132、镜心下移压进底卡（否则镜内会被卡片上沿横切）。

| 编号 | 构图 | 一句话 |
|---|---|---|
| **A1 · 平涂透镜** | 墨圈 + 蓝色页面 | 两色，一眼是"搜索文档"，16px 仍成立 |
| **A2 · 墨线透镜** | 通体墨线 + 页面轮廓 | 纯线稿气质，最克制 |
| **C1 · 层叠镜外** | 来源卡扇出镜外 + 镜内一点 | 保留原 C 的"多来源"叙事 |
| **C1+ / C1++** | 同 C1，整图 +10% / +16% 且镜圈加大 | 定稿取其重的一版 |
| **C2 · 层叠镜内·线** | 三张卡收进镜内，纯线 | 线稿里最干净的多源表达 |
| **C3 · 层叠镜内·涂** | 同 C2，蓝色平涂 | 与 A1 同一家族，小尺寸最稳 |

选定后：把对应 `.icns` 放入应用 Resources，构建脚本的 Info.plist 增加 `CFBundleIconFile`，重新打包安装即可（Finder/Dock 图标缓存可通过重启 Finder 或重登录刷新）。
