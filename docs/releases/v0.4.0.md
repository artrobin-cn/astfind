# Astfind v0.4.0（2026-11-03）

## 本版亮点

### 人物检索 / 找人（实验功能）

- 参考照片 → 本机 Vision 人脸检测/五点对齐 → `buffalo_sc` CoreML 512 维向量 → 本机人脸索引。
- 图片与视频关键帧一起检索；视频命中带 `@mm:ss`，复用 M0.7 跳转。
- 合影参考图显示候选脸选择条（最多 6 张），切换主脸立即重查。
- 人脸索引范围可在设置页选择：**来源内目录** 或 **整个来源**；整个来源前显示文件数确认。
- 召回范围可调：严格 0.60 / 标准 0.50 / 宽松 0.35 / 高召回 0.25。
- 默认关闭；来源级人脸开关与内容 OCR 开关解耦；人脸向量独立表，可一键删除。
- 使用授权活动素材完成参考照片 → 人脸索引 → 图片/视频时间码的端到端验证；具体素材与路径不进入公开仓库。

> 许可边界：`buffalo_sc` 权重为非商用研究许可；权重不随 App/仓库分发。当前版本定位为内部非商用验证；对外发布前需替换为 SeetaFace6/SFace 或取得商业授权。

### 交互优先后台索引（M0.6b）

- 面板可见、输入、打开、预览、QuickLook 时暂停新的后台扫描/内容抽取；隐藏后恢复，不重启 Scanner。
- 真实 UI 打开 p95 **900ms**；扫描暂停代理 p95 **142.8ms**。
- 设置页显示“后台索引已暂停”“待索引内容”“内容提取进度 / ETA”，支持“立即更新”。

### 按来源内容索引范围

- 大型照片/视频库可按来源关闭内容 OCR；`2026` 的 9 万张 JPEG 不再全量 OCR。
- 已完成内容任务记录 `size:mtime` checkpoint，重启/重扫不再反复排队。
- 来源重新接回后，内容队列已排空。

### 设置页排版

- 来源行改为双列索引卡片（内容索引 / 人脸索引），增加行距、路径与操作按钮间距。
- 人脸范围支持“选择目录…”与“全部”；避免误把整个 9 万张照片来源全量排队。

## 安装

1. 下载 `Astfind-0.4.0.dmg`，拖入「应用程序」。
2. 首次启动按提示授予文件夹访问权限；全盘索引需在「完全磁盘访问」中添加 Astfind。
3. 默认快捷键 `⌥⇧F`。

人物检索是实验功能，默认关闭；需要用户自行按许可放置本机模型：

`~/Library/Application Support/Astfind/models/buffalo_sc.mlmodelc`

模型权重不随本项目分发。官方下载、SHA-256、ONNX → CoreML 转换与配置步骤见 [模型下载与配置](../model-setup.md)（仓库内 `docs/model-setup.md`）。
