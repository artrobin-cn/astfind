# Astfind v0.4.1（2026-11-05）

## 本版亮点

### 应用内自动更新

- 菜单栏与设置页均可检查新版本；有新版本时展示版本号、更新时间与中英文更新说明。
- 下载后依次校验文件大小、SHA-256、bundle ID 与代码签名；版本号必须与清单一致。
- 安装到原位置，失败时自动回滚；更新完成后自动重启到新版本。
- 更新清单（`latest.json`）与安装包（zip）由同一 HTTPS 站点提供；未配置更新源时零网络请求，绝不回退到上游更新地址。
- 支持“跳过此版本”与自动检查开关。

### 发布链路

- GitHub Releases、官网与 Homebrew tap 已提供 0.4.1；npm 包已构建并通过本地安装测试，待 npm 2FA 授权后发布。
- 官网新增 `/updates/latest.json` 与更新包，作为应用内更新的稳定入口。
- 构建脚本同时产出 DMG、更新 zip 与 SHA-256，减少手工步骤。

## 验证

- 生产代码路径完成一次 0.4.0 → 0.4.1 的真实升级演练：下载、校验、替换、重启、清理。
- 更新包签名与运行中 App 的 designated requirement 一致。
- 官方更新清单通过解析校验，zip 大小与 SHA-256 与清单一致。

## 安装

1. 从官网下载 [Astfind-0.4.1.dmg](https://astfind.robyn.top/downloads/Astfind-0.4.1.dmg)（国内优先），或使用 [GitHub Releases](https://github.com/artrobin-cn/astfind/releases/tag/v0.4.1)；拖入「应用程序」。
2. 首次启动按提示授予文件夹访问权限；全盘索引需在「完全磁盘访问」中添加 Astfind。
3. 默认快捷键 `⌥⇧F`。

从 0.4.1 起可以直接在应用内检查更新；0.4.0 用户请手动下载本版一次。

## 系统要求

- macOS 14+
- Apple Silicon（arm64）
- 未公证；首次打开需在「系统设置 → 隐私与安全性」放行。
