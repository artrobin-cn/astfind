# @artrobin/astfind-darwin-arm64

Payload package for [Astfind](https://github.com/artrobin-cn/astfind).

It contains `Astfind.zip` (the signed app bundle) and `SHA256SUMS`. Do not install
this package directly; the `astfind` package installs it as an optional dependency
and copies the app to `~/Applications`.

- OS: macOS
- CPU: arm64 (Apple Silicon)
